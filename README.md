# Resume Shortlister

An AI-powered tool that automatically screens resumes against job descriptions and tells you exactly why a candidate is qualified or rejected.

# Features

- Upload resumes (PDF, DOCX, TXT files)
- Paste any job description
- Get instant qualification results
- See exact reasons for rejection
- Get recommendations to improve
- Score from 0-100 for each candidate
- Simple web interface

# How to Run
# Step 1: Install Python
        Download Python from [python.org](https://python.org) if you don't have it

# Step 2: Install required packages
        Open terminal/command prompt and run:
               bash
               pip install PyPDF2 python-docx
